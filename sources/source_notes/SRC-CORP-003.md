# SRC-CORP-003 — 武汉凡谷 2024 年度内部控制评价报告

## 1. 来源信息

武汉凡谷电子技术股份有限公司于 2025-03-29 通过巨潮资讯披露的 2024 年度报告；已核验报告首页主体、标题及披露日期。

## 2. 核心内容摘要

报告覆盖工程项目立项、造价、进度、变更、结算与验收，以及预算、成本费用跟踪和合同拟定、审批、履约、验收监控。

## 3. 可支撑知识资产

POL005、POL006、POL007、POL014、POL015、POL016。

## 4. 可直接作为依据的内容

无。该报告是上市公司公开实践，不对星澜直接产生制度效力。

## 5. 只能参考/类比的内容

项目阶段控制、预算预警、合同审批与履约检查可作为流程设计参考。

## 6. 适用性与局限

PUBLIC_CORPORATE + REFERENCE + ANALOGICAL；制造业工程项目、上市公司治理及金额阈值不得照搬。

## 7. Stage 3 使用建议

以“立项—预算—变更—验收—复盘”的控制闭环组织制度；所有阈值和权限另列为星澜参数。
