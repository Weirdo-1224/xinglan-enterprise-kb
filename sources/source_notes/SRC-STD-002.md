# SRC-STD-002 — GB/T 41304.3-2025

## 1. 来源信息

《知识管理方法和工具 第3部分：会议知识管理》；国家市场监督管理总局、国家标准化管理委员会发布；2025-08-01 发布，2026-02-01 实施，现行。

## 2. 核心内容摘要

为组织保留、整理和利用会议知识提供方法与工具参考。

## 3. 可支撑知识资产

REF016、POL008。

## 4. 可直接作为依据的内容

在合同约定或认证范围内，可作为会议知识管理的技术和管理参考。

## 5. 只能参考/类比的内容

会议分级、纪要模板、归档时限和责任人必须由星澜内部确定。

## 6. 适用性与局限

OFFICIAL + GUIDANCE + ANALOGICAL；GB/T 是推荐性标准，并非对一般企业自动强制。

## 7. Stage 3 使用建议

用于设计会议输入、过程记录、结论沉淀与可检索复用的闭环，不复制标准文字。
