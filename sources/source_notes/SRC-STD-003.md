# SRC-STD-003 — GB/T 44927-2024

## 1. 来源信息

《知识管理体系 要求》；国家市场监督管理总局、国家标准化管理委员会发布；2024-12-31 发布，2025-04-01 实施，现行。

## 2. 核心内容摘要

为组织建立知识管理体系提供公开要求框架。

## 3. 可支撑知识资产

REF017、POL009。

## 4. 可直接作为依据的内容

可作为知识管理体系建设、评价和改进的外部参考。

## 5. 只能参考/类比的内容

文档分类、编号、发布审批、保留期限和权限模型属于星澜内部参数。

## 6. 适用性与局限

OFFICIAL + GUIDANCE + ANALOGICAL；推荐性标准不替代档案法等直接适用规则。

## 7. Stage 3 使用建议

与档案法共同使用：档案法确定底线，标准协助设计知识沉淀与改进机制。
