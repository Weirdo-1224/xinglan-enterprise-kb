# SRC-CORP-010 — 博深股份《投资决策与项目管理制度》（2025年12月修订）

## 1. 来源信息

博深股份有限公司经巨潮资讯披露的《投资决策与项目管理制度》，2025-12-26；已实际打开 cninfo 官方 PDF 核验全文。

## 2. 核心内容摘要

- **投资分类**：固定资产投资（基建/更新改造）、股权投资（新设/增资/收并购）、固定收益投资；区分境内/境外投资。
- **项目投资决策六原则**：合法合规、符合战略且突出主业、规模适度量力而行、严格执行决策程序、按规范流程实施且责任明确、保持独立性。
- **组织与职责**：公司及权属单位为投资和管理责任主体；分级决策权限。
- **流程框架**：立项论证（建议书/可行性研究）→分级审批决策→项目实施（项目部负责制）→实施监督与专项审计→项目验收/中止处理。

## 3. 可支撑知识资产

POL005（项目管理制度）、POL006（项目立项管理办法）、POL007（项目变更管理办法，部分）、REF012。

## 4. EXPLICIT 可直接引用内容

无强制效力。"立项-决策-实施-监督-验收"阶段划分与"项目建议书→可行性研究→分级审批"材料递进结构可作星澜立项流程模板。

## 5. 仅可 REFERENCE / ANALOGICAL 的内容

股权/固定资产投资分类面向实业投资；星澜软件项目立项的分级阈值、审批层级须按星澜项目规模另行设定（SYNTHETIC 参数）。

## 6. Stage 3 使用价值

POL006 可据此设计立项条件（符合战略/规模适度/程序合规）、立项材料清单（项目建议书+可研报告）、分级审批矩阵；POL007 变更可参考其"方案变更须重新履行决策程序"的结构；与武汉凡谷（SRC-CORP-003）的"立项-变更-验收"内控闭环互为印证。

## 7. 关联

与 SRC-CORP-002（PMBOK 第7版）、SRC-CORP-003（凡谷内控评价报告）、SRC-CORP-006（易联众项目预算）配套。
