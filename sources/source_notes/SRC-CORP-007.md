# SRC-CORP-007 — 金种子《经理层业绩考核办法》（2025年12月修订）

## 1. 来源信息

安徽金种子酒业股份有限公司（上交所 600199，国有控股）经上交所披露的《经理层业绩考核办法》，2025-12-03；已实际打开 sse.com.cn 官方 PDF 核验全文。

## 2. 核心内容摘要

- **任期制契约化管理**：考核分年度考核（自然年）+任期考核（3 年）。
- **考核组织**：党委会（前置审议）+董事会（审定办法/指标/结果）+人力资源部（日常办事：拟办法、签岗位聘任协议、组织责任书签订、争议核查、考核档案管理）。
- **指标设定**：总经理全面承接公司年度和任期考核指标（权重 100%）；定量定性结合、定量为主。
- **责任书机制**：董事长与总经理、总经理与副总/财务负责人签订年度/任期经营业绩考核责任书。
- **考核指标体系**（红日药业同类办法印证的结构）：核心指标（利润总额/净资产收益率）+专项任务+发展战略+管理效能+重点项目+督办督查等十类。
- **结果应用**：与薪酬、任免衔接。

## 3. 可支撑知识资产

POL004（绩效管理办法）、REF015。

## 4. EXPLICIT 可直接引用内容

无强制效力。"年度+任期双周期""考核责任书签订""考核档案由人力资源部建立保管"是可借鉴的成熟结构。

## 5. 仅可 REFERENCE / ANALOGICAL 的内容

党委会前置程序为国企特征，星澜（民企）不适用；指标权重与等级线（A/B/C/D 分数段）为该企业参数。

## 6. Stage 3 使用价值

POL004 可据此设计绩效周期（季度+年度）、目标设定（经营业绩责任书/绩效合约）、中期回顾（半年跟踪检查）、结果评价（等级制）、反馈申诉（5 个工作日异议期结构）、结果应用（薪酬/任免/改进计划）全流程；配合东安动力办法中"每半年跟踪检查+预警提醒"机制可补强过程管理。

## 7. 关联

与 SRC-CORP-005（光力科技，总经理绩效评价章节）、SRC-CORP-006（预算考核衔接）配套。
