# SRC-CORP-009 — 华友钴业《供应商管理办法》

## 1. 来源信息

浙江华友钴业股份有限公司（上交所 603799）官网公开发布的《供应商管理办法》（2025-09-30 上传）；已实际打开公司官网 huayou.com 原始 PDF 核验全文。

## 2. 核心内容摘要

- **五大管理原则**：归口管理（集团采购中心）、客户协同、资格审查准入、动态考核、公平竞价诚信竞争。
- **准入**：业务员开发/内外部推荐两种引入方式；书面资料审核+延展审核（远程/现场）两种方式；每种物资原则上保持两家及以上稳定供应商；入库四项基本条件（法人资格/三年无违法违规/履约能力与记录/财务状况）。
- **日常管理**：档案更新与资质有效期复核；资料过期未更新前开展业务须总经理批准。
- **动态考核**：报价行为（串通/恶意低价）、价格、供货质量、交货、服务及合同执行、财务、客户投诉七类异常清单。
- **年度梳理**：每年 2 月重新评审；连续两年未供货自动取消资格。
- **奖惩**：惩罚五级（书面警告→缩减份额→限期整改（保留/暂停业务）→取消资格）；奖励（优先交易/增加份额/优先付款/免检放宽）。
- **监管**：审计部与企管部监督，供应商可投诉。

## 3. 可支撑知识资产

POL012（供应商管理制度）、POL011（采购管理制度，供应商库部分）。

## 4. EXPLICIT 可直接引用内容

无强制效力。准入四条件、七类动态考核异常清单、惩罚五级递进结构可直接作为星澜供应商制度条款骨架。

## 5. 仅可 REFERENCE / ANALOGICAL 的内容

ESG/绿色供应链条款为该企业行业特征；"每种物资两家以上供应商"对软件外包/云服务采购需按品类调整；制造业审核方式（现场审核）对软件供应商改为能力评估。

## 6. Stage 3 使用价值

POL012 可据此设计"准入（资质审查+分级审核方式）→分类建档→动态考核（量化+异常清单）→年度复评→分级淘汰→奖惩"全流程；黑名单/风险供应商处置可直接参考其"取消资格+重新入库须重新走开发流程"设计。

## 7. 关联

与 SRC-MOF-003（企业内部控制应用指引第7号采购业务）配套：官方指引定风险框架，本实践定操作细节。
