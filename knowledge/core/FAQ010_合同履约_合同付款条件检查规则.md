# 合同付款条件检查规则

## 快速问答

### 问：付款条件应检查什么？

答：合同生效、交付或里程碑、验收证据、合规发票、付款比例与日期、质保或扣款条件、收款账户及审批权限。

### 问：有争议能否先付款？

答：由业务、财务和法务评估合同义务与风险；未经授权不得以付款替代争议处理。

本问答用于快速定位规则，不替代上游制度、流程、法律原文或具体合同。遇到事实不足、来源冲突或例外情形时，返回 UNKNOWN 或 CONFLICT 并交责任人判断，不得自行扩展规则。
