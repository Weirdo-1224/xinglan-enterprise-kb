# 项目延期处理规则

## 快速问答

### 问：出现延期迹象是否等到周报再处理？

答：不应等待。立即评估影响和风险等级，指定纠偏措施；涉及批准基线变化时同步发起变更。

### 问：能否口头承诺新工期？

答：不能。涉及合同或验收承诺的日期变更须经内部审批并由有权主体对外确认。

本问答用于快速定位规则，不替代上游制度、流程、法律原文或具体合同。遇到事实不足、来源冲突或例外情形时，返回 UNKNOWN 或 CONFLICT 并交责任人判断，不得自行扩展规则。
