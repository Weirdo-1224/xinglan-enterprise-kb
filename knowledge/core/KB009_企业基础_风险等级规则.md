# 风险等级规则

## 核心内容

风险分为 L1 低、L2 中、L3 高、L4 重大。评级综合发生可能性与对范围、进度、成本、质量、合规、安全、客户关系的影响。

L1 由责任人跟踪；L2 纳入项目或部门风险台账并指定措施；L3 立即通知负责人、PMO 或专业控制部门并形成处置方案；L4 应停止受影响活动，立即升级总经理办公会或授权负责人。评级下降必须有证据，风险关闭必须记录残余风险与责任人确认。

## 使用与维护

查询时应保持企业名称、组织、部门、审批阈值、风险等级和数据分类一致。发现冲突时停止传播冲突值，交由知识所有者按知识治理规则裁决。
