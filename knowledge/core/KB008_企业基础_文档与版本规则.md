# 文档与版本规则

## 核心内容

正式知识以 Markdown 为主，文件名遵循资产类型前缀、编号、中文主题和扩展名。版本使用 vMAJOR.MINOR：不兼容或重大规则变化提升主版本，兼容性补充提升次版本。

每份资产必须有唯一知识编号、状态、来源、上游依赖、适用范围和服务对象。发布前完成内容、来源、权限和格式审核；变更保留版本说明；废止后停止作为现行依据但保留归档与引用链。平台约束按字符数执行：单文件目标不超过 20000 字，超过 100000 字必须拆分；不得把“字”误写为“词”。

## 使用与维护

查询时应保持企业名称、组织、部门、审批阈值、风险等级和数据分类一致。发现冲突时停止传播冲突值，交由知识所有者按知识治理规则裁决。
