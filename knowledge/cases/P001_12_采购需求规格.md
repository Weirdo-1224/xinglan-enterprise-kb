# 智慧园区 AI 数字人服务平台-采购需求规格

本文件为星澜数字科技有限公司合成历史项目材料（SYNTHETIC），不代表真实企业或真实事件。

## 规格编制

采购需求规格由技术负责人韩峥于 2024-03-21 依据解决方案（见 P001_04）编制，作为采购申请 PR-P001-01 的技术附件，参照 REF013 采购需求编制参考组织指标条款，支撑三家供应商按同一口径报价。

## 渲染服务器规格（2 台）

| 指标 | 要求 |
| --- | --- |
| CPU | 不少于 16 核 |
| GPU | 单卡显存不少于 24GB，或双卡单卡显存不少于 16GB |
| 内存 | 不少于 128GB |
| 存储 | NVMe 固态不少于 2TB |
| 电源 | 冗余电源 |
| 质保 | 三年原厂质保 |

## 展示终端规格（14 台）

| 指标 | 要求 |
| --- | --- |
| 屏幕 | 43 或 55 英寸交互显示屏，分辨率 1080P 及以上 |
| 音频 | 内置麦克风阵列与扬声器，支持双向语音交互 |
| 运行要求 | 支持 7×24 小时连续运行 |
| 交互 | 支持触控，预留数字人渲染信号接入接口 |
| 质保 | 三年质保 |

## 配套物料

- 落地支架 14 套
- 机柜配电单元与布线材料一批
- 终端远程管理与监控软件授权

## 到货与验收要求

到货期限为签约后 60 个自然日内，到货后由柯岚、韩峥组织开箱验收与通电测试。实际于 2024-06-10 到货并验收合格（EVT-P001-018）。
