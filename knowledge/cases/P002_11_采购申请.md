# 银行企业知识助手项目-采购申请

本文件为星澜数字科技有限公司合成历史项目材料（SYNTHETIC），不代表真实企业或真实事件。

## 1. 申请背景

按 WBS 计划（P002_07），测试环境搭建工作包于 2024-07-01 启动。项目组评估后确认开发用环境无法满足系统测试的算力、存储与隔离要求，需单独采购知识库测试环境资源。2024-06-20，项目经理周骁会同采购专员柯岚提交采购申请。

## 2. 采购申请单

| 项目 | 内容 |
|---|---|
| 申请编号 | P002-PUR-01 |
| 申请日期 | 2024-06-20 |
| 申请部门 | 银行企业知识助手项目组 |
| 采购标的 | 知识库测试环境资源（详见 P002_12 采购需求规格） |
| 预算金额 | 18 万元 |
| 期望到货 | 2024-08-05 前 |
| 采购方式 | 三家比选 |

## 3. 采购方式判定

按 POL011 采购管理制度，5 万元至 20 万元区间执行三家比选。本项预算 18 万元，落入该区间，由采购专员柯岚组织三家比选，按 SOP016 采购申请与询价流程执行（EVT-P002-015）。

## 4. 审批流程

- 2024-06-20：部门负责人审批通过。
- 2024-06-24：财务经理宋仪复核预算科目（项目预算中已列支测试环境资源 18 万元）。
- 2024-06-25：采购申请获批，转询价与比选。

## 5. 执行结果与偏差

- 2024-07-22：完成三家比选并定标（过程详见 P002_13，EVT-P002-015）。
- 原计划 2024-08-05 前到货；因 CH01、CH02 引起的规格调整，供应商重新备货，实际 2024-09-02 到货（EVT-P002-016），较计划晚约 1 个月。
- 到货延期压缩了系统测试与试运行准备窗口，与人员缺口、版本冲突叠加后直接导致试运行里程碑 2024-09-30 失守（EVT-P002-019）。
