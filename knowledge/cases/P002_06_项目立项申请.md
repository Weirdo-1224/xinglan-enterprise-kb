# 银行企业知识助手项目-项目立项申请

本文件为星澜数字科技有限公司合成历史项目材料（SYNTHETIC），不代表真实企业或真实事件。

## 1. 立项申请基本信息

- 申请日期：2024-02-15
- 批准日期：2024-02-19（EVT-P002-004）
- 审批人：PMO、财务经理宋仪复核、总经理办公会授权负责人批准
- 流程依据：按 SOP003 项目立项流程提交，立项门核对商业目标、合同状态、预算、资源、风险与治理级别。

## 2. 项目概要

| 项目要素 | 内容 |
|---|---|
| 项目名称 | 银行企业知识助手项目（项目编号 P002） |
| 客户 | 区域金融机构（合成），对接窗口信息科技部陈恪 |
| 合同 | P002-C01，280 万元，2024-02-26 签署 |
| 项目类型 | 知识库类交付项目（PTYPE-KB-AGENT） |
| 项目经理 | 周骁 |
| 编制 | 9 人 |
| 预算 | 220 万元 |
| 计划工期 | 2024-03-01 至 2024-11-30 |

## 3. 立项申请要点

- 商业目标：完成银行企业知识助手交付并通过终验，实现金融行业标杆案例复制。
- 资源计划：知识工程组 3 人（负责人孟婕）、技术组 3 人（负责人梁拓）、测试 1 人、实施 1 人、项目经理 1 人。
- 预算构成：人力成本约 190 万元、测试环境资源 18 万元、差旅与外采约 12 万元。
- 主要风险初判：需求基线冻结风险（行内部门分歧未决，见 P002_02）、知识工程产能风险。

## 4. 批准决议

2024-02-19 立项获批：预算 220 万元、编制 9 人、项目经理周骁，计划基线 2024-03-01 至 2024-11-30，需求基线确认里程碑 2024-04-15、知识库试运行里程碑 2024-09-30、终验里程碑 2024-11-30（EVT-P002-004）。治理级别为 PMO 月度监控、里程碑节点检查。

## 5. 立项时点未发现的问题

立项评审未识别出两项后续实质影响项目的问题：一是 2 名知识工程师招聘未到岗（启动时仅 7 人到场，EVT-P002-006）；二是合同试运行付款证据条款缺陷（EVT-P002-005）。两项问题分别在 2024-03-12 与 2025-02-14 显性化为风险 P002-R01 与 P002-R03。
