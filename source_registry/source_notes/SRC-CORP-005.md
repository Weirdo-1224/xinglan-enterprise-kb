# SRC-CORP-005 — 光力科技《经理工作细则》（2025年9月）

## 1. 来源信息

光力科技股份有限公司（深交所创业板 300480）经深交所披露平台发布的《经理工作细则》，2025-09-23；已实际打开 szse.cn 官方 PDF 核验全文。

## 2. 核心内容摘要

- **总经理办公会机制（第五章）**：定期或临时召开，研究决定公司生产经营管理重大问题；议题由总经理办公室提前三天向各部门征集，列议题议程报总经理审批后下发；总经理主持，副总经理/财务总监参加；会议记录专人负责，重大问题出会议纪要由总经理签发后执行；决定事项由责任部门承办并将执行情况回报——即"议题征集→议程审批→开会→纪要签发→督办→执行回报"完整闭环。
- **绩效评价（第六章）**：总经理绩效评价由董事会组织并制定考核方案；薪酬与公司绩效和个人业绩挂钩。
- 报告制度：定期报告（年/半年/季/月）+重大事项及时报告。

## 3. 可支撑知识资产

POL008（会议管理制度）、POL004（绩效管理办法，部分）、REF016。

## 4. EXPLICIT 可直接引用内容

无强制效力。但其"议题提前三天征集""纪要由总经理签发""决定事项由责任部门承办并回报"等流程结构是公开企业实践中的成熟做法，可作为星澜会议 SOP 的结构模板（结构可借鉴，参数须星澜化）。

## 5. 仅可 REFERENCE / ANALOGICAL 的内容

会议频次、参会范围、审批层级为该企业内部设置；上市公司治理背景（董事会/审计委员会报告线）与星澜规模不同，不照搬。

## 6. Stage 3 使用价值

POL008 会议管理制度可据此设计"会前议题征集与议程审批→会中记录→会后纪要签发→待办督办→执行回报→归档"全流程条款；会议纪要保存期限（可对照中坚科技 10 年做法）另行以星澜参数确定。

## 7. 关联

与 SRC-STD-002（GB/T 41304.3 会议知识管理）、SRC-LAW-008（档案法，纪要归档）配套使用。
