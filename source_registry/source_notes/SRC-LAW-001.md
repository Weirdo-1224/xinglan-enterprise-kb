# SRC-LAW-001 — 中华人民共和国劳动合同法

## 2. 核心内容摘要（按章）

- **第一章 总则**：立法宗旨为完善劳动合同制度、保护劳动者合法权益、构建和谐劳动关系；适用范围为中华人民共和国境内的企业、个体经济组织、民办非企业单位等组织与劳动者。
- **第二章 劳动合同的订立**：第十条规定"建立劳动关系，应当订立书面劳动合同"；第十四条规定无固定期限劳动合同的三种情形；第十七条规定劳动合同必备条款（双方信息、期限、工作内容、地点、工时、报酬、社会保险、劳动保护等）；第二十条规定试用期工资底线（不得低于同岗位最低档工资或约定工资的 80%，并不得低于用人单位所在地最低工资）。
- **第三章 履行和变更**：第三十条规定用人单位应"及时足额支付劳动报酬"；第三十一条禁止强迫或变相强迫加班，加班应按国家规定支付加班费。
- **第四章 解除和终止**：第三十八条规定用人单位过错情形下劳动者可解除合同；第四十七条规定经济补偿按工作年限计算（每满一年支付一个月工资）；第四十八条规定违法解除的赔偿金标准（经济补偿的二倍）。
- **第五章 特别规定**：第五十八条规定劳务派遣单位注册资本不得少于 50 万元；第六十三条规定被派遣劳动者"同工同酬"权利。
- **第六章 监督检查**：第七十三至七十九条规定劳动行政部门、工会与相关主管部门的监督职责与举报奖励机制。
- **第七章 法律责任**：第八十二条规定未订立书面劳动合同时"每月支付二倍工资"；第八十七条规定违法解除的"二倍赔偿金"。
- **第八章 附则**：第九十八条规定"自 2008 年 1 月 1 日起施行"。

## 3. 可支撑的知识资产

- **REF001**（劳动合同相关规则）—— 直接对应
- **REF002**（个人信息保护相关规则）—— 部分对应（第八条要求招用劳动者时如实告知工作内容等）
- **POL001**（企业制度_人力资源管理办法）—— 上位强制依据
- **POL002**（企业制度_招聘管理制度）—— 上位强制依据（招聘书面合同、试用期、招用告知义务）
- **POL003**（企业制度_培训管理制度）—— 部分对应（培训可约定服务期与违约金）

## 4. 哪些内容可直接作为依据

- HR/招聘/培训制度中**必须**直接落地的条款：
  - 书面劳动合同的订立（第十条）
  - 试用期期限与工资底线（第十九条、第二十条）
  - 无固定期限劳动合同的触发条件（第十四条）
  - 经济补偿计算（第四十七条）
  - 违法解除的"二倍赔偿金"（第八十七条）
  - 未订立书面合同的"二倍工资"（第八十二条）
- 上述条款应**全文引入**星澜 HR 制度正文，不得改写降级。

## 5. 哪些只能作为企业内部规则的设计参考

- 工时制度的具体标准（应结合《国务院关于职工工作时间的规定》使用）
- 病假与医疗期（应结合原劳动部《企业职工患病或非因工负伤医疗期规定》）
- 经济补偿的具体计算基数（应结合当地工资统计数据与企业薪资结构）
- 内部审批流程、HRBP/招聘专员权限边界（属于星澜内部 SYNTHETIC 参数）

## 6. 适用性 / 局限

- **适用性 = DIRECT**：星澜作为中华人民共和国境内的企业，与劳动者建立劳动关系，**直接适用**本法。
- **强制性**：违反本法"由劳动行政部门责令改正"、"由劳动行政部门责令限期支付"等条款将触发行政处罚、劳动者仲裁、民事赔偿等多重法律后果。
- **不构成**：本法不替代《民法典》合同编对一般民事合同的规定；不替代《个人信息保护法》对个人信息处理的专门规定；不替代《社会保险法》对社保缴费的具体规定。
- **时效**：截至 2026-09-12 访问核验，本法为现行有效版本（2012 年修订后的版本）。后续 Stage 3 生成制度正文前，应再次核验是否有新的修订。

## 7. 后续 Stage 3 应如何使用

- POL001 / POL002 / POL003 在 Stage 3 生成正文时，应**显式引用本法条款号**，并以"本制度依据《中华人民共和国劳动合同法》第 X 条规定……"句式作为强制性条款的依据。
- Stage 3 应基于本法**禁止条款**（如第二十五条关于违约金的限制）反向设计星澜内部制度，确保不出现违法约定。
- 不应将本法直接复制进星澜制度正文；应通过 KB010 业务术语表与 KB005 权限审批基本原则，将法律术语转化为企业内部可操作语言。
