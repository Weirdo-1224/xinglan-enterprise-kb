# SRC-CORP-011 — 龙蟠科技《保密及档案工作管理办法》（2025年7月修订）

## 1. 来源信息

江苏龙蟠科技集团股份有限公司经巨潮资讯披露的《保密及档案工作管理办法》，2025-07-23；已实际打开 cninfo 官方 PDF 核验全文。

## 2. 核心内容摘要

- 依据《档案法》《保守国家秘密法》及境外上市保密档案管理规定制定的企业实践。
- 涉密文件提供/披露前须主管部门批准+保密部门备案；不明确事项先报保密部门定性。
- 提供资料须附书面说明并由接收方保存备查；涉密提供须签保密协议。
- 信息系统与设备存储涉密资料须符合国家规定；发现泄露立即补救并报告。
- 会计档案提供履行法定程序；境内工作底稿境内存放、出境须审批。
- 定期自查+现场/非现场检查+整改监督+违规追责。

## 3. 可支撑知识资产

POL009（文档管理制度）、POL018（知识产权与保密管理制度）、REF009。

## 4. EXPLICIT 可直接引用内容

无强制效力。其上位依据（档案法/保密法）为星澜直接适用法律，但本文件本身仅是企业实践。

## 5. 仅可 REFERENCE / ANALOGICAL 的内容

适用场景为境外发行证券上市活动（窄场景）；对星澜的参考价值在于"涉密文件分级审批+备案+协议+留痕"的管控结构，而非具体条款。

## 6. Stage 3 使用价值

POL009 文档管理制度中"密级文件审批流转""档案提供留痕（书面说明备查）"条款设计可参考；POL018 保密管理中"保密协议+泄露即报+定期自查"机制可参考。价值强度低于其他企业实践来源，定位为补充性 REFERENCE。

## 7. 关联

与 SRC-LAW-008（档案法）、SRC-LAW-011（商业秘密保护规定）配套。
