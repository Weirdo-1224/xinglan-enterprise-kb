# SRC-CORP-006 — 易联众《全面预算管理制度》（2025年11月）

## 1. 来源信息

易联众信息技术股份有限公司（医疗健康信息化软件企业）经巨潮资讯披露的《全面预算管理制度》，2025-11-29；已实际打开 cninfo 官方 PDF 核验全文。

## 2. 核心内容摘要

- **三级预算组织**：预算管理委员会（决策，CEO 主持）→ 财务中心预算部（常设）→ 各职能部门及经营单元（执行，每单元设预算专员）。
- **预算构成**：经营业务预算（项目预算/人员成本预算/部门费用预算/采购预算/固定资产预算/研发项目预算）+ 投融资预算 + 财务预算。
- **项目预算口径**：项目进度、项目收入、项目成本（管理成本/实施成本/采购成本/投标保证费用）与项目回款；区分执行中项目与预投入项目。
- **编制方法**：年度零基预算 + 季度滚动预算（客户多为政府/事业单位的软件企业特征）。
- **执行控制**：先预算后执行、不得突破指标；季度滚动编制。
- **调整机制**：编制基础不成立或重大偏差方可调整，须走申请-审议-审批流程。
- **考核**：预算结果考核在年度经营考核中体现。

## 3. 可支撑知识资产

POL015（预算管理制度）、POL016（项目成本管理制度）、REF014。

## 4. EXPLICIT 可直接引用内容

无强制效力。但项目预算"进度-收入-成本-回款"四要素口径和"零基+滚动"方法可直接作为星澜软件项目预算表结构模板。

## 5. 仅可 REFERENCE / ANALOGICAL 的内容

三级组织名称、预算科目金额、审批层级为该企业参数；客户结构差异影响滚动预算周期设定。

## 6. Stage 3 使用价值

POL015 可据此设计"预算编制（四季度启动）→审批下达→执行控制（先预算后执行）→季度滚动→偏差分析→调整审批→年度考核"闭环；POL016 项目成本归集口径（项目管理/实施/采购成本分类）与研发项目费用化/资本化区分可直接借鉴结构。

## 7. 关联

与 SRC-MOF-002（企业内部控制基本规范）、SRC-LAW-009（会计法）配套：官方规范定框架，本实践定操作结构。
