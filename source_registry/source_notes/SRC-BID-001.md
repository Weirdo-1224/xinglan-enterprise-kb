# SRC-BID-001 — 政府采购需求管理办法

## 1. 来源信息

财政部财库〔2021〕22号；2021-04-30 印发、2021-07-01 施行。已核验财政部通知和附件。

## 2. 核心内容摘要

规定采购需求、采购实施计划、风险控制和审查的要求，强调需求客观明确、与项目目标相匹配。

## 3. 可支撑知识资产

REF013、POL011、POL013。

## 4. 可直接作为依据的内容

星澜参与政府采购项目时，应按该办法在适用范围内执行。

## 5. 只能参考/类比的内容

星澜自有采购可借鉴需求分解、可量化指标和风险审查方法；不得将政府采购人的法定义务直接写成企业内部强制规则。

## 6. 适用性与局限

OFFICIAL + REFERENCE + ANALOGICAL；规则主体是政府采购人，不是普通科技企业内部采购人。

## 7. Stage 3 使用建议

将可量化验收、需求审查和利益冲突控制写成内部设计选择，并明确其并非法律直接规定。
