# 人力资源管理办法



## 1. 目的、对象与触发



规范劳动关系建立、在职管理、考勤休假、异动和离职交接；适用于公司员工及办理用工事项的人力资源、用人部门和审批人员。劳务、实习等非劳动关系须先识别关系性质，不能直接套用员工规则。



## 2. 职责分工



人力资源中心维护员工主数据、合同与考勤规则；用人部门确认岗位事实、排班和工作交付；员工及时提交真实申请与证明；法务风控处理关系性质、处分或解除争议；财务中心按已批准结果办理薪酬结算。



## 3. 领域规则



- 建立劳动关系应依法及时订立书面劳动合同，合同主体、期限、岗位、工作地点、报酬、工时和社会保险等信息不得由口头约定替代。

- 入职登记只收集用工和法定义务所必需的信息；身份证明、联系方式、健康或家庭信息按敏感程度限制访问，另作他用前重新核验合法性基础。

- 请假须说明类型、起止时间和工作交接；病假等证明材料只由授权人员核验。考勤异常由员工说明、主管核实、人力复核，不得仅凭系统异常直接认定违纪。

- 调岗、调薪、工作地点或工时安排发生实质变化时，先核验合同约定、员工沟通和授权，再形成书面变更记录。

- 离职分为员工提出、协商、合同到期和公司依法处理等路径；每一路径分别核对通知、依据、交接、工资与补偿，不得倒推或补造解除理由。



## 4. 审批与关键控制点



- 合同签署状态与到期预警由人力专人复核，未签或即将到期项进入异常清单。

- 考勤、请假审批和工资计算使用同一人员与期间口径；更正必须保留原记录、原因和批准人。

- 涉及处分、解除、重大工伤或群体争议时暂停单方结论，由人力和法务联合审查。



## 5. 例外、停止与升级



- 紧急就医或不可预见缺勤可先报备后补真实材料，但不能补造发生时间；材料长期缺失时由人力按现行规则作出书面处理。

- 劳动关系性质、法定假期或解除依据不清时标记待确认，不向员工给出未经审核的确定性法律结论。



在人力资源事项中，需要跨部门裁决或达到 L3 风险时交对应职能负责人/PMO；违法、安全、舞弊或 L4 重大风险立即停止受影响活动，保全原始证据并升级总经理办公会或授权负责人。例外批准必须限定事项、理由、期限和补救，不能变成长期默认做法。



## 6. 记录与归档



劳动合同及变更、员工告知与签收、考勤原始记录、请假材料、沟通与审批、奖惩或离职依据、交接清单和结算凭证。个人信息按最小范围授权，保存期分别依据劳动、财税、争议处理和业务必要性确定。
