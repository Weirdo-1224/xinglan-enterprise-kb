# 合同管理制度

## 1. 目的、对象与触发

适用于销售、采购、项目、合作、保密、数据处理和其他对内对外合同的起草、审查、谈判、签署、履行、变更、争议和关闭。订单、报价单或线上条款可能构成合同的，也纳入管理。

## 2. 职责分工

业务部门确认交易事实、商业目标和履约能力；财务审核价税、结算、预算与信用；法务风控审查主体、效力、权利义务和争议风险；技术/安全确认技术、数据和知识产权条款；授权签署人作最终承诺；合同管理员维护台账。

## 3. 领域规则

- 签约前核验对方主体、代表权限、交易背景和关联关系，合同名称与实际交易不一致时按实质审查。
- 条款明确标的、范围、交付、验收、价税、付款、知识产权、数据安全、保密、变更、违约、终止和争议解决，避免只有原则无判定条件。
- 非标准条款或偏离模板之处标识风险、建议和接受主体；业务收益不能由法务单独替业务决定，法律红线也不能由业务口头豁免。
- 合同经业务、财务、法务风控按事项会签并由有权人签署；先履行后补签仅限经批准的紧急止损，不能常态化。
- 履约按合同义务清单跟踪交付、客户配合、验收、发票、付款、质保和通知时限；出现偏差及时发出保留权利的书面沟通。
- 变更、解除或和解须评估已履行部分、费用、数据/资产返还、知识产权和争议后果，并与项目基线同步。

## 4. 审批与关键控制点

- 合同台账关联审批版本、签署件、项目/采购编号、收付款节点、履约责任人和到期提醒。
- 签署前比对最终文本与审批文本，页码、附件、签章主体和日期完整后方可归档。
- 付款或开票不替代履约确认，重大违约事实由业务与法务共同固定证据。

## 5. 例外、停止与升级

- 对方要求先开工时，至少完成主体、范围、价格、数据安全和责任边界的临时书面安排并获授权。
- 主体异常、无权代理、无限责任、关键知识产权归属不清、跨境数据或 L4 争议风险未解决时停止签署。

在合同履约事项中，需要跨部门裁决或达到 L3 风险时交对应职能负责人/PMO；违法、安全、舞弊或 L4 重大风险立即停止受影响活动，保全原始证据并升级总经理办公会或授权负责人。例外批准必须限定事项、理由、期限和补救，不能变成长期默认做法。

## 6. 记录与归档

尽调、需求与谈判稿、偏离清单、会签批准、最终签署件、合同台账、履约证据、通知催告、变更、争议、终止和关闭材料。
