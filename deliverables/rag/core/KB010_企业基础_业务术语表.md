# 业务术语表

## 核心内容

| 术语 | 定义 |
|---|---|
| 商机 | 经初步识别、尚未正式立项的客户机会 |
| 需求基线 | 经确认并约束方案、计划和验收的需求版本 |
| WBS | 将范围拆分为可计划、可分工、可验收工作包的结构 |
| 里程碑 | 对阶段成果或决策具有约束作用的节点 |
| 变更 | 对已批准范围、计划、资源、成本或验收指标的调整 |
| 风险 | 尚未发生但可能影响目标的不确定事件 |
| 问题 | 已发生并需要处理的偏差或障碍 |
| 结项 | 完成验收、成本/回款核对、归档和复盘后的项目关闭 |
| 知识沉淀 | 将可复用事实、规则、经验和模板整理为受控知识资产 |

## 使用与维护

查询时应保持企业名称、组织、部门、审批阈值、风险等级和数据分类一致。发现冲突时停止传播冲突值，交由知识所有者按知识治理规则裁决。
