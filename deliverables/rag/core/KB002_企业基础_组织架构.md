# 组织架构

## 核心内容

公司采用职能制与项目制结合的矩阵组织。一级部门为市场营销中心、产品研发中心、项目交付中心、采购供应中心、人力资源中心、财务中心、法务风控中心、综合管理部；治理协同机构为总经理办公会和 PMO。

项目经理对交付目标负责，职能负责人对人员归属、专业能力和专业质量负责。跨部门事项由牵头部门形成明确输入、责任人、完成时点和交付物；重大事项进入授权审批链。

## 使用与维护

查询时应保持企业名称、组织、部门、审批阈值、风险等级和数据分类一致。发现冲突时停止传播冲突值，交由知识所有者按知识治理规则裁决。
