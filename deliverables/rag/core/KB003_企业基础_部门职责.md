# 部门职责

## 核心内容

| 部门 | 核心职责 |
|---|---|
| 市场营销中心 | 市场拓展、客户关系、商机管理、投标协同和合同前商务输入 |
| 产品研发中心 | 产品规划、架构研发、算法工程、知识库和平台技术支持 |
| 项目交付中心 | 项目立项、计划、实施、客户沟通、验收和结项 |
| 采购供应中心 | 采购需求、供应商管理、询比价、采购执行和到货协同 |
| 人力资源中心 | 招聘、入转调离、培训、绩效、岗位能力和人才发展 |
| 财务中心 | 预算、核算、回款、成本、工时和经营分析支持 |
| 法务风控中心 | 合同审核、招投标合规、知识产权、数据安全和风险管理 |
| 综合管理部 | 行政、会议、档案、印章、制度发布和综合协调 |

部门承担专业审核责任不替代业务责任；业务负责人必须对需求真实性和结果负责。

## 使用与维护

查询时应保持企业名称、组织、部门、审批阈值、风险等级和数据分类一致。发现冲突时停止传播冲突值，交由知识所有者按知识治理规则裁决。
