# 绩效管理办法

## 1. 目的、对象与触发

适用于员工和管理者的目标设定、中期回顾、评价校准、反馈申诉与改进；项目成员同时接受项目目标和职能能力双维评价。

## 2. 职责分工

员工与直接主管共同确认目标和证据；部门负责人组织校准并控制分布偏差；人力资源中心维护周期、流程和申诉机制；项目经理提供项目交付事实但不替代职能主管作最终人员评价。

## 3. 领域规则

- 目标应源于部门职责、岗位画像或已批准项目计划，明确衡量口径、目标值、周期、权重和证据来源。
- 目标确认后形成基线；业务显著变化时在周期内记录原因、影响和新版本，不得期末追溯调整以迎合结果。
- 中期回顾同时识别进度、资源、能力和协作障碍，形成由谁在何时完成的支持或纠偏动作。
- 评价区分事实、贡献判断与发展建议；不能只看加班、单一结果或主管印象，也不能重复计算同一成果。
- 校准只解决跨团队尺度差异，不得无证据改写原评价；修改须记录理由和责任人。
- 反馈面谈应说明结论、证据、差距和下一步；员工可对事实、程序或证据提出申诉，申诉人不得因提出异议受不利对待。

## 4. 审批与关键控制点

- 人力在各节点检查目标完整率、证据可用性、异常修改和评价冲突。
- 涉及客户敏感信息的绩效证据使用可核验摘要，不在绩效系统复制超范围材料。
- 低绩效改进计划必须给出具体差距、支持措施、检查点和合理观察期。

## 5. 例外、停止与升级

- 长期请假、调岗或项目取消导致原目标失去基础时，先核验事实并按周期规则调整或另行说明。
- 事实争议、疑似歧视报复或评价与纪律处分混用时暂停结论，由人力负责人复核。

在培训绩效事项中，需要跨部门裁决或达到 L3 风险时交对应职能负责人/PMO；违法、安全、舞弊或 L4 重大风险立即停止受影响活动，保全原始证据并升级总经理办公会或授权负责人。例外批准必须限定事项、理由、期限和补救，不能变成长期默认做法。

## 6. 记录与归档

目标及版本、周期沟通、项目事实输入、个人自评、主管评价、校准理由、反馈确认、申诉材料与改进计划。评价信息按人员管理权限访问，不用于未经说明的其他目的。
