# 招聘管理制度



## 1. 目的、对象与触发



覆盖招聘需求提出、职位发布、简历收集、筛选面试、背景核验、录用审批和候选人信息处置。内部调配参照岗位评价要求，但人员关系变更仍执行人力资源制度。



## 2. 职责分工



用人部门对岗位必要性、工作内容和能力标准负责；HRBP/招聘专员控制渠道、候选人沟通、评价完整性和信息处理；面试官只评价被分配的维度；法务风控处理歧视、隐私或竞业风险；授权负责人批准编制和录用条件。



## 3. 领域规则



- 招聘需求必须关联组织职责、编制或项目资源计划，明确岗位产出、必备能力、可培养能力、到岗时间和预算边界。

- 职位描述不得包含与工作无关的歧视性条件；公开 JD 与内部岗位画像不一致时先由用人部门和人力校准。

- 简历与面试仅收集岗位评价必需信息；敏感个人信息、背景调查和候选人资料转入人才库须满足更严格的告知、授权和访问控制。

- 面试前分配评价维度，面试后分别提交事实证据与结论；不得先统一口径再补写个人评价，也不得把学校、年龄等替代岗位能力。

- 录用条件、职级、薪酬、试用安排和到岗承诺经授权后方可发出；口头沟通不得超出已批准边界。

- 未录用候选人按既定目的和必要期限删除、匿名化或经合法程序转入人才库，并响应查询、更正等权利请求。



## 4. 审批与关键控制点



- HR 在发布前核对需求编号、岗位名称、预算、面试组和数据字段。

- 录用审批对照需求版本、评价证据和利益冲突声明，任何条件变化重新确认。

- 第三方招聘渠道只能取得完成委托所需数据，合同中明确安全、保密、返还和删除要求。



## 5. 例外、停止与升级



- 紧急项目用人可并行安排面试与编制确认，但未获授权前不得发出确定性录用承诺。

- 背景信息互相冲突、候选人提出隐私异议或评价疑似歧视时停止推进，转人力负责人和法务复核。



在招聘事项中，需要跨部门裁决或达到 L3 风险时交对应职能负责人/PMO；违法、安全、舞弊或 L4 重大风险立即停止受影响活动，保全原始证据并升级总经理办公会或授权负责人。例外批准必须限定事项、理由、期限和补救，不能变成长期默认做法。



## 6. 记录与归档



招聘需求、JD 版本、渠道告知、候选人同意或其他处理依据、结构化评价、录用审批、沟通记录、背景核验结果及删除/转库记录。候选人资料不得进入无权限群聊或个人长期存储。
