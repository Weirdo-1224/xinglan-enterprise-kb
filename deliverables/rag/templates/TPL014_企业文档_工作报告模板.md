# 工作报告模板

## 使用场景与边界

按周期或专题汇报事实、结果、问题、判断和后续安排。

本模板把 SOP013、SOP023 的现行要求转换为记录结构，不增加审批权限、金额阈值或法律义务。历史案例中的经验只可作为可选检查提示；具体人员、金额和项目名称不得从案例复制到新记录。

## 适用角色

报告编制人、内容责任人、专业会签人、阅读对象、签发人。

## 填写规则

1. 报告用于汇报，不在正文中隐性请求批准。
2. 事实、推断和建议分别表达。
3. 敏感数据按阅读权限裁剪。
4. 事实、判断、假设和建议分别记录；证据不足时标记“待确认”并指定责任人。
5. 金额注明币种和含税口径，日期使用 YYYY-MM-DD，人员与项目优先引用稳定业务ID。
6. 任何审批结论均记录批准人、权限依据、日期、条件和对应版本。

## 状态与审批信息

| 状态 | 进入条件 | 可执行动作 | 退出证据 |
|---|---|---|---|
| 草拟 | 已创建编号并开始收集材料 | 补充事实和证据 | 必填字段完整 |
| 评审中 | 输入完整且已提交专业复核 | 记录意见、退回或附条件项 | 评审意见闭环 |
| 待批准 | 专业意见一致或分歧已提交裁决 | 授权人批准、退回或否决 | 有权人书面决定 |
| 执行中 | 已批准且前置条件满足 | 按批准版本执行 | 完成证据齐全 |
| 已关闭 | 完成证据经验证 | 归档并更新关联台账 | 版本、批准和归档记录齐全 |

## 输出结构

正式输出依次包含：文档控制、业务背景、主体字段、评审与批准、行动或结论、附件与归档。结构化导出时，至少保留以下首要字段顺序：报告编号与版本｜报告主题与期间｜数据截止日｜范围与口径｜关键结果｜计划与实际对比。

## 检查清单

- [ ] 期间与数据口径是否一致。
- [ ] 指标是否可追溯。
- [ ] 问题是否有行动。
- [ ] 是否误写未批准决定。
- [ ] 必填字段、版本、责任人、审批状态和归档位置均完整。
- [ ] 敏感信息按最小必要原则记录和分发。
- [ ] 未将案例建议、类比来源或个人经验写成强制规则。

## 关联制度与流程

- 直接依据：SOP013、SOP023
- 使用前核对上述资产的现行版本和适用范围。
- 发现来源冲突时停止传播冲突结论；证据不足时返回 UNKNOWN，需要裁决时记录提交对象。
