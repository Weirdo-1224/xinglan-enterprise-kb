# 绩效评价反馈与改进计划模板

## 使用场景与边界

绩效期末评价、反馈面谈以及需要时制定改进计划。

本模板把 SOP027、SOP028 的现行要求转换为记录结构，不增加审批权限、金额阈值或法律义务。历史案例中的经验只可作为可选检查提示；具体人员、金额和项目名称不得从案例复制到新记录。

## 适用角色

员工、直属主管、校准参与人、HR、支持责任人。

## 填写规则

1. 评价与校准必须以可核验证据为基础。
2. 员工确认收到不等同表示同意。
3. 改进计划不自动等同处分或解除。
4. 事实、判断、假设和建议分别记录；证据不足时标记“待确认”并指定责任人。
5. 金额注明币种和含税口径，日期使用 YYYY-MM-DD，人员与项目优先引用稳定业务ID。
6. 任何审批结论均记录批准人、权限依据、日期、条件和对应版本。

## 状态与审批信息

| 状态 | 进入条件 | 可执行动作 | 退出证据 |
|---|---|---|---|
| 草拟 | 已创建编号并开始收集材料 | 补充事实和证据 | 必填字段完整 |
| 评审中 | 输入完整且已提交专业复核 | 记录意见、退回或附条件项 | 评审意见闭环 |
| 待批准 | 专业意见一致或分歧已提交裁决 | 授权人批准、退回或否决 | 有权人书面决定 |
| 执行中 | 已批准且前置条件满足 | 按批准版本执行 | 完成证据齐全 |
| 已关闭 | 完成证据经验证 | 归档并更新关联台账 | 版本、批准和归档记录齐全 |

## 输出结构

正式输出依次包含：文档控制、业务背景、主体字段、评审与批准、行动或结论、附件与归档。结构化导出时，至少保留以下首要字段顺序：评价记录ID｜员工ID、周期与目标版本｜证据截止日｜员工自评｜逐项目标事实与达成｜个人贡献与岗位能力。

## 检查清单

- [ ] 是否排除周期外信息。
- [ ] 同一成果是否重复计分。
- [ ] 改进目标是否少量明确。
- [ ] 环境变化时是否更新版本。
- [ ] 必填字段、版本、责任人、审批状态和归档位置均完整。
- [ ] 敏感信息按最小必要原则记录和分发。
- [ ] 未将案例建议、类比来源或个人经验写成强制规则。
