# 银行企业知识助手项目-需求变更申请

本文件为星澜数字科技有限公司合成历史项目材料（SYNTHETIC），不代表真实企业或真实事件。

## 1. 变更申请单

| 项目 | 内容 |
|---|---|
| 变更编号 | P002-CH01 |
| 申请日期 | 2024-05-20 |
| 申请人 | 客户信息科技部陈恪（行内需求） |
| 受理人 | 项目经理周骁 |
| 变更类型 | 需求范围变更 |
| 流程依据 | 按 SOP009 项目变更控制流程提交，申请单格式按 TPL007 |

## 2. 变更内容

客户要求知识助手首期范围在制度、产品、操作指引三类知识域基础上，新增信贷、合规、票据三类知识域，覆盖行内零售信贷、公司信贷、监管合规与票据业务知识。

## 3. 变更原因

行内业务部门在需求基线 v1.0（2024-05-10 确认）确认后持续提出纳入诉求（售前调研阶段遗留分歧，见 P002_02）。行内要求知识助手上线即可覆盖主要业务条线，避免上线后二次扩建。

## 4. 影响评估

| 评估项 | 评估结果 |
|---|---|
| 工期影响 | 增加 2 周 |
| 工作量影响 | 约 18 万元工作量（知识采集、加工、质检与测试） |
| 质量影响 | 新增知识域与既有域口径需统一，质检规则需扩展 |
| 采购影响 | 测试环境存储与 OCR 通道需上调（后续形成规格 V1.1，见 P002_12） |
| 费用影响 | 客户不同意增费，费用处理待商务确认 |

评估人：项目经理周骁、知识工程负责人孟婕；评估完成日期：2024-05-24。

## 5. 审批与决策

- 2024-05-24：变更申请连同影响评估提交审批。
- 2024-05-31：变更专题会 MTG-P002-04 召开，参会人为周骁、市场负责人、陈恪。会议决定：先行实施新增知识域实施，费用挂起，待后续商务谈判打包处理（EVT-P002-011）。
- 决策背景：客户明确不同意增费；项目处于基线延期 25 天后恢复期，为避免范围僵持影响交付关系，采取了范围先行、费用脱钩的处理方式。

## 6. 实施与验证

- 2024-06 至 2024-08：完成三类新增知识域采集加工与入库，质检通过。
- 费用处理：18 万元费用挂起；2024-10-17 纠偏会议 MTG-P002-09 将变更费用打包谈判授权市场负责人（EVT-P002-021）；截至结项，该费用未获客户补偿，计入项目超支（见 P002_23）。

## 7. 复盘标注

本次变更的实际执行存在偏差：按 POL007 项目变更管理办法的变更-合同联动要求，费用影响未获确认前不应启动实施；本项目采用挂起变通，最终费用未回收，成为超支 45 万元的最大单项构成。
