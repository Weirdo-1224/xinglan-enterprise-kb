# 智慧园区 AI 数字人服务平台-招标文件关键条款

本文件用于查询 P001 智慧园区 AI 数字人服务平台投标时的招标文件要求，包括最高限价 400 万元、项目工期 2024-02-01 至 2024-10-31（含终验），以及资格、商务、技术、否决项和价格/技术/服务/业绩评分标准；不作为其他项目的通用制度。

本文件为星澜数字科技有限公司合成历史项目材料（SYNTHETIC_DERIVED），条款结构参照公开案例 SRC-CASE-016（多模态数字人全栈平台成交公告，ANALOGICAL，仅作结构类比，主体、金额、日期与结果不移植），不代表真实企业或真实事件。

## 文件背景

2023-11-20，政企园区运营单位（合成）发布智慧园区 AI 数字人平台招标文件（项目编号 ZL-PARK-2023-017，合成编号），星澜当日启动投标评估（EVT-P001-001）。本文件摘录招标文件关键条款，供投标文件逐条响应使用。

## 资格条款

| 条款编号 | 内容 |
| --- | --- |
| ZG-01 | 独立法人资格，营业执照有效 |
| ZG-02 | ISO9001 质量管理体系认证 |
| ZG-03 | ISO27001 信息安全管理体系认证 |
| ZG-04 | 近三年同类数字人或智慧园区项目业绩不少于 2 个 |
| ZG-05 | 拟投入项目经理具备 PMP 或同等资质 |

## 商务条款

| 条款编号 | 内容 |
| --- | --- |
| SW-01 | 项目工期 2024-02-01 至 2024-10-31（含终验） |
| SW-02 | 付款节点：合同签订后 30% 预付款、平台上线后 40%、终验合格后 30% |
| SW-03 | 质保期：终验合格后 12 个月 |
| SW-04 | 投标报价不得超过最高限价 400 万元 |
| SW-05 | 交付物：平台及相关设备、接口集成、培训与文档（原始表述较笼统，后经澄清明确，见 P001_26） |

## 技术条款

| 条款编号 | 内容 |
| --- | --- |
| JS-01 | 数字人并发交互能力不少于 200 路 |
| JS-02 | 语音交互平均响应时间不超过 1.5 秒 |
| JS-03 | 知识库问答准确率不低于 90% |
| JS-04 | 园区系统集成不少于 5 类 |
| JS-05 | 展示终端覆盖园区公共区域 12 个点位 |
| JS-06 | 平台满足等保二级要求 |

## 评分标准

| 条款编号 | 评分项 | 分值 |
| --- | --- | --- |
| PF-01 | 价格 | 30 分（低价优先法折算） |
| PF-02 | 技术 | 40 分（方案 20 分、参数响应 20 分） |
| PF-03 | 服务 | 15 分（实施与质保服务方案） |
| PF-04 | 业绩 | 15 分（类似项目案例） |

## 条款使用说明

星澜于 2023-11-27 完成招标文件审查（见 P001_26），针对 SW-02 付款节点与 SW-05 交付物定义两处表述模糊条款提出书面澄清并获得答复；资格、商务、技术、评分条款的逐条响应分别见 P001_28、P001_29、P001_30、P001_31。
