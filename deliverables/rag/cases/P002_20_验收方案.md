# 银行企业知识助手项目-验收方案

本文件为星澜数字科技有限公司合成历史项目材料（SYNTHETIC），不代表真实企业或真实事件。

## 1. 方案编制说明

- 初版编制：2024-10，随基线 v2.0 计划同步编制。
- 修订：2025-01-20 变更 P002-CH04 获批后，验收范围由 200 条样本扩大至 500 条，本方案于 2025-01-24 修订为 V2.0（EVT-P002-024）。
- 流程依据：按 SOP010 项目验收流程编制，经客户验收组与项目经理周骁双方确认。

## 2. 验收组织

- 客户方：客户验收组（信息科技部牵头，业务部门联合参与），窗口陈恪。
- 我方：项目经理周骁牵头，孟婕、梁拓及测试工程师参加。
- 验收时间窗口：2025-03-10 至 2025-03-15（对应纠偏基线终验节点 2025-03-15）。

## 3. 验收维度与通过标准

| 维度 | 验收内容 | 通过标准 |
|---|---|---|
| 功能 | 问答、引用溯源、版本提示、运营统计 | 用例全部通过 |
| 知识质量 | 抽样条目回答准确性与引用可溯源 | 准确率达到合同约定阈值，引用可溯源率 100% |
| 权限 | 组织映射可见性、角色叠加控制 | 权限测试用例 100% 通过，无越权 |
| 性能 | 200 并发下响应时间 | 达到合同约定阈值 |
| 文档 | 交付物清单、运维手册、培训记录 | 齐全并移交 |

## 4. 验收样本设计（CH04 后口径）

样本总量 500 条，按知识域分层抽样：制度类 40%、产品类 30%、操作指引类 20%、新增信贷合规票据类 10%；题型覆盖事实问答、流程指引、合规引用三类。样本由客户验收组从真实业务场景中抽取，我方不参与选题。

## 5. 验收流程与整改闭环

验收测试（2025-03-10）→ 问题记录与整改（限期闭环）→ 复核 → 签署验收报告。整改项不关闭的，验收报告注明附条件结论；付款证据事项不纳入本方案验收范围，按合同争议通道单独跟踪（见 P002_30）。

## 6. 实际执行对照

- 2025-03-10：按 500 条样本执行验收测试，发现 2 项整改（EVT-P002-027）。
- 2025-03-15：整改复核通过，终验 passed_with_conditions（EVT-P002-028），过程详见 P002_21。
