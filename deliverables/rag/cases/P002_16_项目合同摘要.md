# 银行企业知识助手项目-项目合同摘要

本文件为星澜数字科技有限公司合成历史项目材料（SYNTHETIC），不代表真实企业或真实事件。

## 1. 合同基本信息

| 项目 | 内容 |
|---|---|
| 合同编号 | P002-C01 |
| 合同金额 | 280 万元 |
| 签署日期 | 2024-02-26 |
| 客户 | 区域金融机构（合成），窗口信息科技部陈恪 |
| 我方签约主体 | 星澜数字科技有限公司 |
| 合同状态 | 争议已降级，尾款挂起跟踪 |

合同签署当日记录："签署合同但试运行付款证据条款未按法务意见细化"（EVT-P002-005）。

## 2. 关键条款摘要

- 付款条款：20% 预付款（56 万元）、30% 试运行款（84 万元）、50% 终验款（140 万元）。
- 试运行付款证据：合同正文为原则性表述，未细化列举可验证证据（争议根源，详见 P002_15）。
- 交付与验收：交付银行企业知识助手系统与知识库，验收依据合同及经确认的需求基线。
- 违约条款：含延期违约金约定；知识产权与保密条款按私有化部署口径约定。

## 3. 付款执行情况

| 节点 | 金额 | 计划/申请时间 | 执行情况 |
|---|---|---|---|
| 预付款 20% | 56 万元 | 2024-03 初 | 2024-03-05 到账 |
| 试运行款 30% | 84 万元 | 2025-02 初（试运行 2025-01-12 启动后） | 2025-02-14 被客户暂缓，引发争议（EVT-P002-025）；2025-02-21 补充确认证据口径后解除暂缓，与争议相关部分继续挂起（EVT-P002-026） |
| 终验款 50% | 140 万元 | 2025-03-15 终验后 | 按合同进入支付流程，其中 28 万元尾款因付款条件争议挂起 |

## 4. 收入确认与争议现状

- 2025-03-15 终验 passed_with_conditions，收入确认 252 万元（EVT-P002-028）。
- 尾款 28 万元因付款条件争议延期挂起，由法务与市场负责人持续跟踪（EVT-P002-026、EVT-P002-029）。
- 合同争议处理路径按 SOP018 与 FAQ010 合同付款条件检查规则执行；复盘确认合同签订时法务意见未落实为根因（见 P002_15、P002_30）。
